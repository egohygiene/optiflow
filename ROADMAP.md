# Roadmap

## v0.1 — Safe inventory and exact evidence

- [x] Rust CLI foundation
- [x] Conservative recursive discovery
- [x] Actual-content classification
- [x] Optional `ffprobe` inventory
- [x] SQLite state and unchanged-path cache
- [x] Size-narrowed complete BLAKE3 hashing
- [x] Exact duplicate reports
- [x] Immutable review plans
- [x] JSON schemas and pipeline contract
- [x] CI, unit tests, integration test, and smoke test

## v0.2 — Transactional image optimization

- [ ] Define adapter capability and tool-record contracts
- [ ] Add named image profiles without one universal output format
- [ ] Start with lossless OxiPNG optimization
- [ ] Add temporary same-filesystem outputs
- [ ] Validate dimensions, frame count, alpha, color, and complete decode
- [ ] Add execution attempts, artifacts, validations, and commit records
- [ ] Add backup and quarantine policies
- [ ] Add interruption and insufficient-space fixtures

## v0.3 — Video and audio optimization

- [ ] Add FFmpeg capability discovery per installed build
- [ ] Add archive, balanced, space-saver, web, and pipeline profiles
- [ ] Preserve master-plus-optimized output strategies
- [ ] Validate streams, duration, decode completion, and truncation
- [ ] Record encoder configuration and version provenance

## v0.4 — Perceptual relationships

- [ ] Add versioned image perceptual fingerprints
- [ ] Add Chromaprint audio evidence
- [ ] Add sampled video frame and audio evidence
- [ ] Add explainable detector-specific scores
- [ ] Add review workflow; never auto-delete perceptual matches

## v0.5 — Containment and ecosystem integration

- [ ] Detect time-aligned video subsections
- [ ] Add updateable platform-delivery profiles
